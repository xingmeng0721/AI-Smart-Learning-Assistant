# RAG 智能学习助教 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建从文档接入、混合检索、重排精排到流式生成与引用溯源的 RAG 智能学习助教，支持多轮对话与知识库增量更新。

**Architecture:** 分层解耦（Ingestion → Embedding/VectorStore → Retrieval → Rerank → Generation → API → Agent）。核心"幻觉控制 + 引用溯源"贯穿检索与生成；采用 TDD + 频繁提交，每条链路均可量化验证。

**Tech Stack:** Python 3.11(conda airag-tutor) / FastAPI / Uvicorn / ChromaDB / scikit-learn / Ollama(HTTP) / pytest
